# 📌 Sobre o Projeto

O **ODB (Ordem dos Detetives Brasil)** é um projeto desenvolvido em **Java**, inspirado no universo investigativo e policial, trazendo um sistema temático voltado para gerenciamento, investigação e organização de detetives.

O projeto possui estilo clássico desktop, refletindo aplicações Java desenvolvidas nos anos 2000.

---

# 🕵️ Funcionalidades

- Cadastro de detetives
- Sistema de investigações
- Registro de casos
- Controle de suspeitos
- Banco de dados local
- Interface desktop Java
- Sistema de consultas
- Gerenciamento de ocorrências

---

# ⚙️ Tecnologias Utilizadas

- Java
- Java Swing
- JDBC
- Banco de Dados Local
- NetBeans/Eclipse

---

# 🖥️ Interface

O sistema utiliza interface gráfica clássica Java Swing, trazendo uma aparência nostálgica dos sistemas desktop antigos.
